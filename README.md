# SubTrack

SubTrack is a personal finance web app that helps users track their monthly 
subscriptions and recurring expenses in one centralized dashboard, so they 
never pay for a forgotten service again.

## Team Members
- Lesedi Pride Iketleng
- Farai Dale Rwambiwa

## Tech Stack
Next.js (App Router), TypeScript, Tailwind CSS

## Getting Started
\`\`\`bash
npm install
npm run dev
\`\`\`
Open [http://localhost:3000](http://localhost:3000) to view the app.
